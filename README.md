# Cyber Operations — Water Utility Incident Response

**MSc Cyber Security · Cyber Operations (7COM1069) · University of Hertfordshire**  
Chirag Menariya

> **Fictional university exercise.** The scenario uses Thames Water as its setting. The incident, public health claims and media examples described here were created for coursework.

## Project overview

This case study examines how a simulated cyber incident at a water utility can create two parallel response problems: investigating suspicious activity in an operational technology (OT) environment and communicating with the public while unverified claims spread.

## What I did

- Reviewed coursework packet-capture data and its CSV export to assess suspicious network activity and document the evidence available to responders.
- Used a threat model to connect risks in the scenario to defensive measures, including IT/OT network segmentation, engineering workstation hardening, industrial protocol monitoring and outbound traffic controls.
- Analysed mock group chats, social media posts and news clips to examine how impersonation and repeated claims can make unverified information seem credible.
- Proposed a coordinated response covering detection, containment, investigation, public communications, recovery and lessons learned.

## Defensive priorities

| Area | Proposed response |
| --- | --- |
| OT security | Coordinate containment with plant operators and review network boundaries, engineering workstation access and monitoring coverage. |
| Forensic investigation | Preserve packet captures and logs, build a timeline and distinguish observed activity from inferred impact. |
| Public communications | Publish timestamped updates through verified channels. State what has been confirmed, what remains under investigation and when the next update is due. |
| Recovery | Confirm operational integrity before restoring affected systems and use the incident review to prioritise improvements. |
